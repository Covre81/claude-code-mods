# Lixeira Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every `rm` Claude runs in Bash and every `Remove-Item`/`del`/`rm`/`rd` it runs in PowerShell sends the files to the Windows Recycle Bin instead of deleting them for good.

**Architecture:** A new isolated mod `lixeira/`. Its `tool.call` hook detects a delete in the command line and prepends a definition that shadows the delete command: in Bash a `rm()` function that calls `powershell.exe -File lixeira.ps1`; in PowerShell a dot-sourced `remove-item.ps1` that defines a `Remove-Item` function calling the same script in-process. The shell still expands globs, variables and `cd`; `lixeira.ps1` imitates `rm`'s messages and exit code and moves each item with `Microsoft.VisualBasic.FileIO.FileSystem` `SendToRecycleBin`.

**Tech Stack:** TypeScript (Claude Code mod API, `claude-code/testing`), Windows PowerShell 5.1.

**Spec:** `docs/superpowers/specs/2026-10-13-lixeira-design.md`

## Deviations from the spec (decided while planning, 2026-10-13)

1. **`.catch` never re-runs the original.** Spec §3.3 says the `.catch` returns `next(e)`. If the error happens *after* `next(rewritten)` ran, that would run the original `rm` and delete for good what was left. The plan uses `.catch(($, e, next) => (next.called ? { deny } : next(e)))`. A deny after `next` undoes nothing (index.d.ts:3956), so it is safe.
2. **PowerShell side is a dot-sourced file, not an inline function.** `rewrite` for PowerShell returns `. '<root>/hooks/remove-item.ps1'; <command>`. Tested 2026-10-13: `$PSScriptRoot` inside a dot-sourced function points at the file's folder, so the function finds `lixeira.ps1` with no path baked in. The same file is used by the real test (no copy that can drift).
3. **`SupportsShouldProcess` on the `Remove-Item` function.** Claude often writes `Remove-Item x -Confirm:$false`; without it, PowerShell says "parameter cannot be found". Tested 2026-10-13: it works.
4. **Wildcard expansion and absolute paths in the script.** PowerShell does not expand `*.tmp` for a function's `[string[]]` parameter, so the script expands it. In-process, .NET's current folder differs from PowerShell's location, so the script always deletes `Get-Item(...).FullName`, never the relative string.
5. **No `--` in the Bash prefix.** Tested 2026-10-13: `powershell.exe -File s.ps1 -- x` passes `--` into `$args`, which would turn the user's `-rf` into a path. The prefix is `powershell.exe -NoProfile -NonInteractive -File '<script>' "$@"`; the script treats a user `--` as rm does (end of flags).
6. **Final stderr line.** The script builds 🗑 with `[char]::ConvertFromUtf32(0x1F5D1)` so the `.ps1` stays ASCII (PowerShell 5.1 misreads UTF-8 without BOM). Task 2 checks how it renders in Git Bash; if it shows as `?`, the line starts with `lixeira:` instead (exact code given in Task 2).

```tsx
import type { Register } from 'claude-code'

export type Shell = 'bash' | 'powershell'

// ponytail: copy of guarda's tokenize/PREFIXES — plugins load isolated, an import across mods may not exist when installed.
function tokenize(text: string): string[] {
  const words: string[] = []
  const re = /"((?:[^"\\]|\\.)*)"|'([^']*)'|(\S+)/g
  for (let m = re.exec(text); m; m = re.exec(text)) words.push(m[1] ?? m[2] ?? m[3] ?? '')
  return words
}

const PREFIXES = new Set(['sudo', 'command', 'exec', 'env', 'nohup', 'time', 'then', 'do', 'else', '!'])
const PS_DELETE = /(?:^|[;|{(\n]|&&)\s*(?:remove-item|rm|del|erase|ri|rd|rmdir)(?=\s|$|[;|)}])/i

/** Does the line run rm (Bash) or a Remove-Item alias (PowerShell) as a command? A false positive only adds a harmless prefix. */
export function hasDelete(command: string, shell: Shell): boolean {
  if (shell === 'powershell') return PS_DELETE.test(command)
  return command.split(/&&|\|\||;|\||\n/).some(seg => {
    const words = tokenize(seg.trim().replace(/^[({]+\s*/, ''))
    while (words.length && (PREFIXES.has(words[0]!) || /^[A-Za-z_]\w*=/.test(words[0]!))) words.shift()
    return words[0] === 'rm'
  })
}

/** The command with the delete shadowed by the mod's scripts in `hooks` (a folder without single quotes). */
export function rewrite(command: string, shell: Shell, hooks: string): string {
  if (shell === 'powershell') return `. '${hooks}/remove-item.ps1'; ${command}`
  return `rm() { powershell.exe -NoProfile -NonInteractive -File '${hooks}/lixeira.ps1' "$@"; }; ${command}`
}

export const register: Register = () => {}
```

- [ ] **Step 1: Write `lixeira/hooks/lixeira.ps1`** (ASCII only: Windows PowerShell 5.1 misreads UTF-8 without BOM)

```powershell
# Sends rm / Remove-Item targets to the Windows Recycle Bin, imitating rm's messages and exit code.
# Flags: -r -R --recursive -Recurse, -f --force -Force (clusters like -rf); others ignored; `--` ends flags.
Add-Type -AssemblyName Microsoft.VisualBasic
$recurse = $false; $force = $false; $flags = $true; $paths = @()
foreach ($a in $args) {
  $s = [string]$a
  if ($flags -and $s -eq '--') { $flags = $false; continue }
  if ($flags -and $s -match '^--?(recursive|recurse)$') { $recurse = $true; continue }
  if ($flags -and $s -match '^--?force$') { $force = $true; continue }
  if ($flags -and $s -cmatch '^-[A-Za-z]+$') { if ($s -cmatch '[rR]') { $recurse = $true }; if ($s -cmatch 'f') { $force = $true }; continue }
  if ($flags -and $s.StartsWith('--')) { continue }
  $paths += $s
}

$sent = 0; $failed = $false
function Fail([string]$p, [string]$why) { [Console]::Error.WriteLine("rm: cannot remove '$p': $why"); $script:failed = $true }

foreach ($p in $paths) {
  # Git Bash spells C:\x as /c/x; a bare /c is the drive root, not "current folder on C:".
  $q = $p -replace '^Microsoft\.PowerShell\.Core\\FileSystem::', '' -replace '^/([a-zA-Z])(?=/|$)', '$1:'
  if ($q -match '^[a-zA-Z]:$') { $q += '\' }
  try {
    # Always FullName: in-process, .NET's current folder is not PowerShell's location.
    $items = @(if ($q -and (Test-Path -LiteralPath $q)) { Get-Item -LiteralPath $q -Force } elseif ($q -match '[*?]') { Get-Item -Path $q -Force -ErrorAction SilentlyContinue })
  } catch { Fail $p $_.Exception.Message; continue }
  if (-not $items.Count) { if (-not $force) { Fail $p 'No such file or directory' }; continue }
  foreach ($i in $items) {
    $link = [bool]($i.Attributes -band [IO.FileAttributes]::ReparsePoint)
    if ($i.PSIsContainer -and -not $link -and -not $recurse) { Fail $p 'Is a directory'; continue }
    try {
      if ($i.PSIsContainer) { [Microsoft.VisualBasic.FileIO.FileSystem]::DeleteDirectory($i.FullName, 'OnlyErrorDialogs', 'SendToRecycleBin') }
      else { [Microsoft.VisualBasic.FileIO.FileSystem]::DeleteFile($i.FullName, 'OnlyErrorDialogs', 'SendToRecycleBin') }
      $sent++
    } catch { Fail $p $_.Exception.Message }
  }
}

if ($sent) {
  $what = if ($sent -eq 1) { 'item enviado' } else { 'itens enviados' }
  [Console]::Error.WriteLine("$([char]::ConvertFromUtf32(0x1F5D1)) $sent $what para a Lixeira do Windows")
}
exit [int]$failed
```

- [ ] **Step 2: Write `lixeira/hooks/remove-item.ps1`** (ASCII only)

```powershell
# Dot-sourced by the lixeira mod before a PowerShell command: Remove-Item and its aliases (rm, del, erase, ri, rd, rmdir) send to the Recycle Bin.
function Remove-Item {
  [CmdletBinding(SupportsShouldProcess)]
  param(
    [Parameter(ValueFromPipeline, ValueFromPipelineByPropertyName, Position = 0)][Alias('FullName', 'PSPath', 'LiteralPath')][string[]]$Path,
    [switch]$Recurse,
    [switch]$Force
  )
  begin { $all = @() }
  process { $all += $Path }
  end {
    if (-not $all.Count -or -not $PSCmdlet.ShouldProcess($all -join ', ')) { return }
    $f = @()
    if ($Recurse) { $f += '-r' }
    if ($Force) { $f += '-f' }
    & (Join-Path $PSScriptRoot 'lixeira.ps1') @f -- @all   # `--`: a path starting with '-' stays a path
  }
}
```

```tsx
export const register: Register = on => {
  on('tool.call', { tool: ['Bash', 'PowerShell'] }, ($, e, next) => {
    if (e.tool !== 'Bash' && e.tool !== 'PowerShell') return next(e)
    const sh: Shell = e.tool === 'Bash' ? 'bash' : 'powershell'
    const command = String(e.command ?? '')
    const hooks = `${$.plugin.root.replace(/\\/g, '/')}/hooks`
    if (hooks.includes("'") || !hasDelete(command, sh)) return next(e)
    return next({ ...e, command: rewrite(command, sh, hooks) } as typeof e)
  }).catch(($, e, next) =>
    // Before next: let the original run (a lixeira bug must not block the shell; guarda still holds rm -rf).
    // After next: the rewritten delete already ran — running the original now would delete for good.
    next.called ? { deny: 'A lixeira falhou depois de rodar o comando. Confira o resultado antes de repetir.' } : next(e),
  )
}
```
